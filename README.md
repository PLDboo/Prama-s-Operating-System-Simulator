# Prama OS Simulator 🖥️

## Overview
Prama OS Simulator is a Python-based operating system simulation that demonstrates core OS concepts such as process management, file systems, and UI interaction.

## Features
- Multi-application system (Calculator, Notepad, Terminal, File Manager)
- Window management system
- Simulated file system
- Desktop and taskbar UI
- Command execution via terminal

## Project Structure
- `apps/` → Applications (Calculator, Notepad, etc.)
- `core/` → Core OS logic
- `ui/` → Desktop and UI components
- `utils/` → Utilities and system helpers
